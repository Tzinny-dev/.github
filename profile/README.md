## Who we are

Tzinny builds small, focused open-source libraries and frameworks for
developers — from a contract-first TypeScript backend to ML testing,
differential-privacy data synthesis, procedural game asset generation, and
GNN explainability. Every project ships with a stable CLI, a documented API,
and a dedicated docs site.

## Projects

| Project | Description | Stack | Status |
| --- | --- | --- | --- |
| [**tzin**](https://github.com/Tzinny-dev/tzin) | Contract-first TypeScript backend framework — end-to-end typing, OpenAPI 3.1, MCP server, realtime channels | TypeScript, TypeBox, Node.js, Bun, Cloudflare Workers | Active |
| [**modeltest**](https://github.com/Tzinny-dev/modeltest) | Unit tests for machine learning models — like pytest, but for your model | Python, scikit-learn, PyTorch, SHAP, MLflow | Beta |
| [**synthpriv**](https://github.com/Tzinny-dev/synthpriv) | Tabular data synthesis with formal differential privacy guarantees | Python, SDV, Opacus, anonymeter | Beta |
| [**sprout-toolkit**](https://github.com/Tzinny-dev/sprout-toolkit) | Deterministic procedural 2D asset generation for Expo + react-native-skia | Python, Typer, Pillow, SkSL | Active |
| [**graph-explain**](https://github.com/Tzinny-dev/graph-explain) | Explainability library for Graph Neural Networks — 14 methods, built-in metrics | Python, PyTorch, PyG, DGL | Beta |

See the full catalog with docs and demos at [tzinny.com/products](https://tzinny.com/products).
